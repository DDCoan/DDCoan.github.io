Researcher Portfolio Website Improvement Plan

Goal: Improve clarity, credibility, and research communication while preserving the minimalist style and dynamic animations.

1. Improve First Screen (Hero Section)
Problem

The landing section looks visually appealing but does not clearly communicate the research identity or impact.

Actions

Replace generic tagline with a clear research identity

Example:

Machine Learning Researcher
AI for Science · Representation Learning · Climate & Physics

Add a 1-line research thesis

Example:

I study how machine learning models represent and reason about physical systems.

Add credibility signals

Minimal badges or chips:

PhD @ ISTA
Google Fellowship
NeurIPS / ICML
2. Improve Research Content Hierarchy
Problem

Projects currently resemble generic portfolio items, not research work.

Actions

For each project card include:

project title

1-sentence contribution

venue / status

links

Example:

Cyclife Dataset
Understanding representation alignment in tropical cyclones.

ICML Submission 2026

[Paper] [Code] [Dataset]

Keep descriptions short and scannable.

3. Create Clear Section Narrative
Problem

Scrolling lacks strong structure.

Actions

Use section headers to guide readers:

Hero

Research
Selected Publications
Datasets & Open Source
Talks
Contact

This improves information scanning.

4. Improve Animation Usage
Problem

Animations are mostly decorative.

Actions

Use animation to guide attention:

section reveal on scroll

project card hover interactions

smooth navigation transitions

Example hover interaction:

Project card hover
→ reveal links: paper | code | demo

Optional addition:

subtle scroll indicator arrow

5. Improve Project Cards
Problem

Cards look slightly template-like.

Actions

Add a visual anchor per project

Possible elements:

small figure

dataset visualization

model diagram

Benefits:

increases engagement

improves memory of projects

6. Add "Selected Publications" Section
Problem

Researchers expect a clear publications list.

Actions

Minimal format:

Selected Publications

Representation Alignment in Scientific Foundation Models
NeurIPS 2025
[paper] [code]

Learning Identifiable Representations
ICML 2024
[paper]

Only include important papers.

7. Improve Contact Section
Problem

Current contact area feels generic.

Actions

Add icon row:

Email
Google Scholar
GitHub
Twitter / X
LinkedIn

Enhancement:

copy-to-clipboard email button

8. Add Research Interests Section
Purpose

Help visitors quickly understand expertise.

Example:

Research Interests

Representation Learning
Scientific AI
Causal Structure
Climate & Physics Modeling

Keep it very concise.

9. Improve Typography Hierarchy
Problem

Hierarchy between titles and text could be stronger.

Suggested sizes
Hero title: 48–56px
Section title: 28–32px
Body text: 16–18px

Also slightly increase line height for readability.

10. Add Impact Metrics Strip
Purpose

Quickly communicates research output.

Example:

Publications: 12
Citations: 800+
Open Source Stars: 1.2k
Datasets Released: 3

Minimal horizontal strip below hero section.

11. Improve Navigation
Problem

Navigation is slightly hidden.

Actions

Add sticky header:

About | Research | Publications | Projects | Contact

Keep header thin and minimal.

12. Add Dark / Light Mode
Benefits

modern design expectation

better reading experience

minimal visual change

13. Improve Loading Performance
Goal

Portfolio pages should load under ~2.5 seconds.

Actions

compress images

avoid large animation libraries

keep animation duration under ~150ms

14. Improve Mobile Experience
Actions

Ensure:

project cards stack well

text remains readable

animations do not block scrolling

Many visitors will view the page on mobile.

15. Add a Subtle Personal Motif

Minimalist sites often feel generic.

Add one unique element related to research.

Examples:

animated research keywords

physics-inspired background motion

representation space visualization

Example rotating keywords:

Representation Learning
Scientific AI
Climate Modeling
Causal Discovery
Highest Priority Improvements

Clearer hero research statement

Better research project cards (paper/code links)

Add publications section

Add research interests

Add credibility signals

Improve navigation
